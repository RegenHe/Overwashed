# Overwashed

`Overcooked! 2` BepInEx 5 assistant that controls a selected local chef. It can also add a game-internal virtual controller player for the bot without requiring a system virtual-gamepad driver.

It automatically collects dirty plates, carries them to a sink, and washes them. Optional features include plating and serving completed orders, player avoidance, fast interactions, and extreme dashing.

Press **F8** to toggle the bot. Click the top-right icon while enabled to open its settings.

Use the player selector in the settings panel to choose a local chef. The default, **Last local**, follows the last available local player. Add or remove the virtual bot player from a lobby or chef-selection screen, before entering a level.

Current version: **1.7.0**
