# Overwashed

`Overcooked! 2` BepInEx 5 assistant that controls the current keyboard chef without creating an additional player.

It automatically collects dirty plates, carries them to a sink, and washes them. Optional features include plating and serving completed orders, player avoidance, fast interactions, and extreme dashing.

Press **F8** to toggle the bot. Click the top-right icon while enabled to open its settings.

Current version: **1.5.10**
